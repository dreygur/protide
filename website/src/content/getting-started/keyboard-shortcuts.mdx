# Keyboard shortcuts

These are the bindings registered by the app. They use <kbd>Ctrl</kbd> on every platform, including
macOS — <kbd>Cmd</kbd> is not currently bound.

| Shortcut | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Send the current request |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save the request to its `.http` file |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | Toggle the sidebar (Explorer) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | Toggle the mock server panel |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | Toggle the console panel |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Toggle the docs panel |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | About Protide |
| <kbd>F1</kbd> | Keyboard shortcut help |
| <kbd>Esc</kbd> | Dismiss the open overlay, dropdown, or modal |
| <kbd>Ctrl</kbd>+<kbd>Q</kbd> | Quit |

The same actions are available from the menu bar: **Request → Send / Save**,
**View → Toggle Sidebar / Toggle Mock Server**, and **Help → Keyboard Shortcuts**.
